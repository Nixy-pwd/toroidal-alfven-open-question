# 环形真空场中的 Alfvén 算子：谱结构与耗散增强（研究笔记）

Nov 23, 2026 · @sl

## 摘要

对实心环中的真空环向场 Φe\_φ/R，线性化电阻–粘性 MHD 在非轴对称扇区（环向模数 n≠0）上的 Alfvén 算子可以精确写成“逆五次齐次矩阵乘子的 Leray 压缩”，其谱是一条显式的带，且曲率让它等价于一个带变系数 Coriolis 力的惯性波问题。在此基础上，“强环向场是否增强耗散”被精确归约为一个嵌入本征值问题；数值上看到了增强，但它比纯相混合弱，并且由曲率制造的频带延伸部分控制。

| --- | --- |

## 1. 设定

Ω 是轴对称实心环，子午截面 D 在 R>0 的半平面内；文中数值均取圆截面 (R−R₀)²+Z²≤a²、R₀=1。粘性–电阻不可压 MHD 取边界条件：速度滑移 v·n=0、n×curl v=0；磁场理想导体壁 B·n=0、n×curl B=0。

令 h = e\_φ/R（curl h = 0、div h = 0、h·n = 0）。对任意Φ，(u,B) = (0, Φh) 是无外力方程的精确稳态。线性化得 ∂ₜw = (ΦS − Γ)w，w=(v,b)，其中 S(v,b) = (P\[(curl b)×h\], curl(v×h))，Γ = diag(ν curl curl, η curl curl)。S 与Γ 都与绕轴旋转交换，可按 e^{inφ} 分解；n≠0 扇区中环向磁通自动为零，谐和场不出现，Γ 正定且预解紧。

**能量法盲区（VERIFIED）。** 对任意稳态 (u\*, Φh + B₁\*)，扰动能量式中与稳态有关的项只有 −∫v·D(u\*)v + ∫b·D(u\*)b + ∫J\*·(b×v)，其中用到恒等式 (b·∇B)·v − (v·∇B)·b = J·(b×v)。Φ 不出现，所以单调能量稳定边界与环向场强度严格无关。强环向场的任何致稳作用只能通过非单调、有限时间的机制体现，这就是下面要研究的对象。

## 2. 结果一：乘法算子分解与谱带

在 n≠0 扇区，S\_n 是一个逐点可逆矩阵乘子 M 与 Leray 投影的组合，其平方在速度分量上是一个齐次 −4 的厄米矩阵乘子的压缩。分量顺序为 (R, φ, Z)，α = R⁻²：

```latex
S_n=\begin{pmatrix}0&-PM^*\\ M&0\end{pmatrix},\qquad M=\alpha\begin{pmatrix}in&0&0\\2&in&0\\0&0&in\end{pmatrix},\qquad S_n^2=-\mathrm{diag}\big(K,\ MPM^*\big)
```

```latex
K=P\,(R^{-4}N)\,P,\qquad N=\begin{pmatrix}n^2+4&2in&0\\-2in&n^2&0\\0&0&n^2\end{pmatrix},\qquad \mathrm{spec}(N)=\{(\sqrt{1+n^2}-1)^2,\ n^2,\ (\sqrt{1+n^2}+1)^2\}
```

关键是 curl(v×h) 对无散 v 不含导数：M v = α(in v + 2v\_R e\_φ)；而 (curl b)×h 的非梯度部分恰好是 −M\*b。两条公式都用笛卡尔坐标下的中心差分独立核对过（相对误差 1.2e-8）。

**推论（VERIFIED）。**

1. 谱包含：对无散 v，⟨Kv,v⟩ = ∫R⁻⁴Nv·v̄，逐点夹在 N 的特征值之间，故

```latex
\sigma(S_n)\subset \pm i\,\big[\alpha_{\min}(\sqrt{1+n^2}-1),\ \alpha_{\max}(\sqrt{1+n^2}+1)\big],\qquad \alpha_{\min}=R_{\max}^{-2},\ \alpha_{\max}=R_{\min}^{-2}.
```

2. 无零本征值：ker M = 0；若 PM\*b = 0，则可算出 b = ∇(R²q)/(−in)，由调和性与 Neumann 条件得 b = 0。故 S\_n 可逆，谱在 0 附近有宽为 α\_min(√(1+n²)−1) 的隙。
3. 本质谱等于整条带（SUPPORTED，局部高频无散波包构造 Weyl 序列）。与 1 合并：**离散谱为空**，带外与隙中没有任何本征值；剩下的只有带内嵌入本征值。

注意带比经典剪切 Alfvén 范围 \[nα\_min, nα\_max\] 宽。以 n=1、a=0.5 为例，经典范围是 \[0.444, 4.0\]，带是 \[0.184, 9.66\]。两端的延伸完全来自曲率项 2v\_R e\_φ，延伸部分内部没有 Alfvén 共振面。

## 3. 结果二：曲率等价于 Coriolis 力

纯环向场的力线曲率在波动力学上等价于一个有效转速 α(R)e\_Z = e\_Z/R² 的 Coriolis 力。S\_n 在截面上是零阶伪微分算子，其主符号给出与磁–Coriolis 波完全相同的色散关系：

```latex
(\lambda^2-n^2\alpha^2)^2=4\alpha^2\lambda^2\cos^2\theta,\qquad \cos\theta=\xi_Z/|\xi|.
```

这个关系由两条独立路径得到：一是消去 b 后的压力方程的主部，二是直接计算 Leray 投影后 2×2 符号矩阵的特征值。压力方程为

```latex
\partial_R\!\Big(\frac{RA}{\Delta}\partial_R\pi\Big)+\frac{R}{A}\partial_Z^2\pi-Q\pi=0,\quad A=\lambda^2-n^2\alpha^2,\quad \Delta=A^2-4\alpha^2\lambda^2,
```

在 Δ<0 处双曲、Δ>0 处椭圆。三个几何对象决定射线动力学：

- **特征线。** 令 c(R) = (λ²R⁴ − n²)/(2λR²)。射线满足 |dR/ds| = |c|、|dZ/ds| = √(1−c²)，即两族曲线 Z ∓ G(R) = const，G′ = √(1−c²)/|c|。符号不显含 Z，所以 ξ\_Z 守恒。
- **转折线 |c| = 1。** 射线在此形成尖点，径向速度反号、族交换。
- **Alfvén 共振线 R\_A = √(n/λ)（c = 0）。** 由于 ξ\_Z 守恒而 c 的符号不变，射线不能穿越 R\_A；接近时 |ξ| → ∞，在凸截面中以锯齿状按几何级数逼近（启发式，未严格证明）。这是共振线余法丛上的 Lagrange 汇，即相混合在射线层面的形式。

当 λ 落在带的延伸部分（R\_A 不在 D 内）时，只剩下惯性波式的反射台球，分析与内波吸引子理论同类，但带变系数与转折线。

## 4. 结果三：弛豫增强的精确判据

在 n≠0 扇区、滑移边界条件下，“Φ→∞ 时任意初值在固定时刻 τ 的 L² 范数都可任意小”当且仅当 K = P(R⁻⁴N)P 在 H¹ 中没有本征向量（SUPPORTED）。

这是把 Constantin–Kiselev–Ryzhik–Zlatoš（Annals 2008）的抽象定理 1.4 套用到 L = −iS\_n。定理要求 Γ 自伴、正、谱离散，且 ‖Lψ‖ ≤ C‖ψ‖\_{H¹(Γ)}、e^{iLt} 在 H¹(Γ) 上有界。逐条核对如下。

| 条件 | 本问题中的情况 |
| --- | --- |
| Γ 正、谱离散 | n≠0 扇区无谐和场，Gaffney 不等式给出紧嵌入 |
| ‖Lψ‖ ≤ C‖ψ‖\_{H¹} | S\_n 在 L² 上有界，平凡成立 |
| e^{iLt} 在 H¹ 上有界 | M 是光滑乘子且保持无散与切向；P 在光滑有界区域上保持 H¹；形式域不含自然边界条件。故 S\_n 在 H¹ 上有界，B(t) ≤ e^{Ct} |

S\_n 的 H¹ 本征向量 (v, Mv/(iλ)) 与 K 的 H¹ 本征向量 v 一一对应。ν≠η 不影响结论。

**边界条件不是细节。** 无滑移条件 v=0 下，Alfvén 群不保持 v|∂Ω = 0，第三条失效，CKRZ 不能直接套用；这不推出不增强，只是判据不再可用。

由结果一，带外无本征值，所以判据只剩“带内有无 H¹ 嵌入本征函数”这一个问题。

## 5. 结果四：Pohozaev 型恒等式

任何嵌入本征值只能由边界诱导；但由伸缩与 Z 平移生成的乘子族对任何有界环都不足以排除它们（SUPPORTED，手算）。

G = R⁻⁴N 关于以轴上一点为中心的伸缩是齐次的（x·∇G = −4G），Leray 投影与伸缩可交换。设 Kv = μv，v ∈ H¹，以 (x−x₀)·∇v̄ 为乘子分部积分；由 div v = 0、v·n = 0，内部压力项消失，边界上又有 ∇q = (G−μ)v，得

```latex
4\mu\|v\|^2=\oint_{\partial\Omega}\big((x-x_0)\cdot n\big)\,(G-\mu)v\cdot\bar v\,dS,\qquad 0=\oint_{\partial\Omega}n_Z\,(G-\mu)v\cdot\bar v\,dS .
```

- **正面。** 在伸缩不变的区域（全空间、以轴上点为顶的锥）中右端为零，而 μ > 0，故无 H¹ 本征函数。
- **反面（严格）。** 要从恒等式得矛盾，需要 (x−x₀)·n · (G−μ)|\_切平面 ≤ 0 处处成立。轴在区域外，(x−x₀)·n 必变号；在变号点切平面上的 G−μ 须同时 ≤ 0 与 ≥ 0，这要求 n\_Z = 0。但 n\_Z = 0 时 (x−x₀)·n = ±R ≠ 0，矛盾。切平面上 G 的特征值为 α²(√(n²+n\_Z²) ± |n\_Z|)²，这一步用到了它。

所以处理嵌入本征值必须用与 P 不可交换的乘子（会出现新的交换子项），或转向微局部的径向估计。

## 6. 数值结果

固定 ν 时，所有算例的最小阻尼率都随 Φ 增长，与弛豫增强一致；但增长慢于纯相混合，且薄环更慢。

&#91;embedded content: 本会话 Galerkin 计算 · 取 p = 30/38/46 一致的值 · n=2、3 与去曲率对照只收敛到 ε = 1e-5\]

由标度关系 衰减率(Φ,ν) = Φ·f(ν/Φ)，只需在 Φ=1 下扫描 ε = ν。n=1、a=0.5 的局部指数 f ∝ ε^β 为 β ≈ 0.58–0.73，即衰减率 ∝ ν^β Φ^(1−β)；纯相混合的预期是 β = 1/3。去掉曲率项 2v\_R e\_φ 的对照增长更快（局部 β ≈ 0.44–0.5）。所以曲率耦合是削弱而不是加强了耗散增强。

**方法。** 对 n≠0，无散约束可显式消去：v\_φ = (i/n)\[∂\_R(R v\_R) + R∂\_Z v\_Z\]，故只需对截面内分量 (v\_R, v\_Z) 用 Legendre 乘积多项式（全次数 ≤ p）展开，并用零空间施加 u·n = 0。对 K 做 Rayleigh–Ritz，对 ΦS − Γ 做完整特征分解。

| 核对 | 结果 |
| --- | --- |
| curl(v×h) 与 (curl b)×h 公式，笛卡尔差分 | 相对误差 1.2e-8、9.9e-9 |
| Ritz 值落在结果一的带内 | 是（n=1, a=0.5：\[0.228, 6.45\] ⊂ \[0.184, 9.66\]） |
| 均匀场对照（应无增强） | f/ε = 14.31 对所有 ε 不变，等于 curl curl 首特征值 |
| 分辨率收敛 | n=1, a=0.5 在 ε = 1e-6 处 p=30/38/46 给出 5.710/5.742/5.739 (×1e-4) |

**最小阻尼模位于曲率制造的带延伸部分。** ε → 0 时，最小阻尼模的频率收敛到 λ₀：n=1, a=0.5 为 0.3321；a=0.3 为 0.4149；n=2 为 0.809；n=3 为 1.278。四者都低于经典剪切 Alfvén 下界 nα\_min（分别为 0.444、0.592、0.889、1.333），即都落在只有曲率才产生、且没有 Alfvén 共振线的延伸带中。a=0.5 的模式集中在外壁附近的双曲区，向椭圆区衰减。

**射线动力学的对应（SUPPORTED，弱）。** 用不变量 Z ∓ G(R) 做射线台球：a=0.5 时 λ₀ = 0.3321 处每次撞壁的有限时间 Lyapunov 指数约 −0.012，而邻近 λ = 0.330、0.3326 处为 −0.15 到 −0.28（强吸引子或转折线与壁的角点捕获）；a=0.3 时 λ₀ = 0.4149 处指数 ≈ 0，120 步内无周期轨道，而 λ = 0.41 是周期 10 的吸引子。也就是说，最小阻尼频率恰好是射线吸引最弱或无吸引的频率，这与惯性波吸引子理论的图景一致。但这是几个点上的吻合，不是系统扫描。

**是否存在 H¹ 嵌入本征函数。** 对 n=1, a=0.5 和 n=2, a=0.5，所有 Ritz 向量的粗糙度 ⟨Cv,v⟩ 都随 p 大致按 p² 增长（n=1：750 → 3380，p=16 → 34），没有稳定的光滑向量，支持“无嵌入本征值”。薄环 a=0.3 是例外：λ ≈ 0.41491 的 Ritz 向量在 p = 22/28/34/40 时粗糙度为 1446/2245/1959/2332，不随 p² 增长，频率稳定到 5 位；但耗散问题在 ε ≤ 1e-8 时不收敛（p=30/38/46 给出 f/ε = 1120/2008/1622）。它是真本征函数还是一个粗糙度增长很慢的准模，目前无法判定（UNKNOWN）。射线动力学在该频率上近乎中性，按内波理论的类比更倾向于准模。

## 7. 新颖性评估

物理机制本身（相混合、Alfvén 连续谱、惯性波吸引子）都不新；可能新的是它们在这个具体算子上的精确组合与严格表述（UNKNOWN，并未穷尽检索）。

| 条目 | 最近的已知工作 | 差别 | 判断 |
| --- | --- | --- | --- |
| 弛豫增强判据 | [Constantin–Kiselev–Ryzhik–Zlatoš 2008](https://arxiv.org/abs/math/0509663) | 他们做标量对流扩散；这里是 MHD 系统、环形域、并指出边界条件的作用 | 应用层面可能新 |
| 内波 / 惯性波的零阶算子谱论 | Dyatlov–Wang–Zworski 2021、Li 2023、[内波遍历动力学](https://arxiv.org/pdf/2306.13834v1)、Ralston 1973 | 那里是常系数、标量、无内部共振线；这里变系数、矩阵值、带转折线与共振汇 | 结构类同，具体算子未见处理 |
| 曲率–Coriolis 对应 | 未检索到 | 等离子体文献很可能以其他形式写过 | UNKNOWN |
| 弯曲场中带耗散的剪切 Alfvén 模 | [Reese–Rincon–Rieutord 2004](https://arxiv.org/abs/astro-ph/0409120) | 球壳、偶极场、力线端点在边界上；阻尼按 E^{1/2}。这里是闭合力线、实心环 | 不重叠 |

我认为最有可能成立的新贡献是：(i) K = P(R⁻⁴N)P 的分解与带公式；(ii) “强环向场是否增强耗散” ⇔ 嵌入本征值问题的归约；(iii) 数值上发现的“曲率延伸带控制最小阻尼、增强弱于纯相混合”。都不是大结果，但合起来是一篇短文的分量。

## 8. 开放问题与下一步

核心开放问题只有一个：K = P(R⁻⁴N)P 在带内是否有 H¹ 嵌入本征函数。它一旦解决，弛豫增强问题就随之解决。

1. **薄环候选模（最优先）。** 用更高分辨率（p ≥ 70，需要比这里的 7 GB 内存更多，或改用局部元素）把 ε ≤ 1e-8 的最小阻尼率收敛。若 ε → 0 时 f/ε 饱和，就是嵌入本征值的强证据，意味着薄环 n=1 扇区不弛豫增强，与我原先的猜想相反。
2. **旋转数分析。** 把边界返回映射写成两个对合的复合（不变量 Z ∓ G(R) 已给出），对 λ 画出旋转数与 Lyapunov 指数曲线；检验“最小阻尼频率 = 最弱吸引子或无理旋转数”这一对应是否稳健。
3. **严格方向。** 在 Morse–Smale 型频率区间内，尝试把 Colin de Verdière–Saint-Raymond 的边界版径向估计推广到变系数情形，并把 Alfvén 共振线作为内部汇处理。这是一个较大的项目。
4. **文献。** 按“toroidal field curvature Coriolis analogy”“incompressible Alfvén spectrum vacuum toroidal field”在等离子体经典文献（Goedbloed–Poedts 教材、Freidberg）中核对结果一二是否已知。
